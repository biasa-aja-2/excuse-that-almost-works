The one line a gamer texts the boss to skip work on GTA 6 launch week: the water is off in the whole street, there is no shower, and nobody is coming in smelling like yesterday. Pure Python stdlib; it writes the line to `entry.txt`.

> Water's off in my whole street till 2pm and I can't shower, I'm not coming in smelling like yesterday.

## Why this line

- **Believable first:** a whole-street water outage is a real, specific, boring detail a tired manager can picture — not a wild story, not a dead grandmother, a flat tyre or a sudden fever.
- **The laugh comes from its own logic:** instead of inventing a tragedy, it admits the embarrassing truth (no shower) and lands on "smelling like yesterday".
- **Reads like a hurried text:** one line, plain words, no setup, no explanation, no signature.
- **It almost works:** true-sounding and specific enough to believe — and a strict manager could still answer "come in anyway", which is exactly the point of the bounty.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`): 102 characters, 19 words, one line, no trailing newline.
